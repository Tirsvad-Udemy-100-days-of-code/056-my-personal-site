# 056 My Personal Site

Day 56 of Udemy's "100 Days of Code: The Complete Python Pro Bootcamp": a personal CV website served by Flask, built in three lecture steps. This wiki explains what each step taught.

| Page | What you learn |
| --- | --- |
| [Lecture 1: Render HTML](Lecture-1-Render-HTML) | A Flask server that renders `index.html` from `templates/` |
| [Lecture 2: Static Files](Lecture-2-Static-Files) | CSS and images from `static/`, and the browser cache |
| [Lecture 3: CV Site](Lecture-3-CV-Site) | A website template organised, adapted and filled with your own content |
| [Architecture](Architecture) | The layers, the ports and the tests that protect them |
| [Running the Project](Running-the-Project) | `.venv`, install, run, test, Doxygen and screenshots |

The code is in the [repository](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/056-my-personal-site). Python 3.13 or later, and Flask as the only runtime dependency.
