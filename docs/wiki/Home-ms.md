# 056 My Personal Site

Hari ke-56 kursus Udemy "100 Days of Code: The Complete Python Pro Bootcamp": laman web CV peribadi yang dihidangkan oleh Flask, dibina dalam tiga langkah kuliah. Wiki ini menerangkan apa yang dipelajari pada setiap langkah.

| Halaman | Apa yang anda pelajari |
| --- | --- |
| [Kuliah 1: Paparkan HTML](Lecture-1-Render-HTML-ms) | Pelayan Flask yang memaparkan `index.html` daripada `templates/` |
| [Kuliah 2: Fail statik](Lecture-2-Static-Files-ms) | CSS dan imej daripada `static/`, serta cache pelayar |
| [Kuliah 3: Laman CV](Lecture-3-CV-Site-ms) | Templat laman web yang disusun, disesuaikan dan diisi dengan kandungan anda sendiri |
| [Seni bina](Architecture-ms) | Lapisan, port dan ujian yang melindunginya |
| [Menjalankan projek](Running-the-Project-ms) | `.venv`, pemasangan, larian, ujian, Doxygen dan tangkapan skrin |

Kod terdapat dalam [repositori](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/056-my-personal-site). Python 3.13 atau lebih baharu, dan Flask sebagai satu-satunya kebergantungan semasa larian.
