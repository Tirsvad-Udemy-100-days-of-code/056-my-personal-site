# 056 My Personal Site

Dag 56 af Udemys "100 Days of Code: The Complete Python Pro Bootcamp": en personlig CV-hjemmeside serveret af Flask, bygget i tre lektionstrin. Denne wiki forklarer, hvad hvert trin lærte os.

| Side | Hvad du lærer |
| --- | --- |
| [Lektion 1: Vis HTML](Lecture-1-Render-HTML-da) | En Flask-server, der viser `index.html` fra `templates/` |
| [Lektion 2: Statiske filer](Lecture-2-Static-Files-da) | CSS og billeder fra `static/` og browserens cache |
| [Lektion 3: CV-siden](Lecture-3-CV-Site-da) | En hjemmesideskabelon, der organiseres, tilpasses og fyldes med dit eget indhold |
| [Arkitektur](Architecture-da) | Lagene, portene og de tests, der beskytter dem |
| [Kør projektet](Running-the-Project-da) | `.venv`, installation, kørsel, test, Doxygen og skærmbilleder |

Koden findes i [repositoriet](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/056-my-personal-site). Python 3.13 eller nyere, og Flask som eneste afhængighed ved kørsel.
