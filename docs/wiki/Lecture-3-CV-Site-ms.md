# Kuliah 3: Laman CV

**Matlamat:** menukar templat laman web kepada laman CV peribadi anda sendiri.

![Kuliah 3](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/056-my-personal-site/raw/branch/main/docs/screenshots/lecture-3-cv-site.png)

## Langkah

1. Dapatkan templat HTML dan CSS percuma. Pautan zip kursus telah tamat tempoh, jadi reka letak mengikut contoh CV awam kursus itu; HTML dan CSS ditulis untuk projek ini.
2. Letakkan HTML dalam `templates/` serta CSS dan imej dalam `static/`, kemudian betulkan setiap laluan dengan `url_for`.
3. Gantikan kandungan contoh dengan kandungan anda sendiri: nama, gambar, kemahiran dengan bintang, pendidikan, minat dan projek.
4. Semak setiap laluan aset dalam satu ujian.

## Apa yang kami peroleh

- Cara menyusun templat ke dalam `templates` dan `static`.
- Jinja: pemboleh ubah dan gelung mengisi halaman daripada data, jadi kandungan tidak ditulis keras dalam HTML.
- Data dan penanda dipisahkan: objek `Profile` menyimpan kandungan, templat hanya memaparkannya.
- Asas kebolehcapaian: teks `alt` untuk gambar dan `aria-label` pada bintang.
- Menghormati lesen dan memberi kredit apabila menggunakan semula templat.
- Privasi: metadata gambar dibuang sebelum diterbitkan.
